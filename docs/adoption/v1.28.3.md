# Upstream v1.28.3 adoption

Issue: youngsecurity/collie#147.

## Pinned integration

This merge adopts the upstream tag onto the fork. The work is on a branch cut from `dev-joe`; it
reaches `main` through `dev-joe` and one pull request. Operator decision.

- Fork base: `ebca626d` (`1.24.2+ys.2`).
- Upstream: `v1.28.3` (`93d13224`). The merge base is `v1.24.2` (`744faa49`).
- The tag, not `upstream/main`: `main` is on the Edge line (`v1.29.0-edge.1`), which is out of
  scope. The release should be upstream's release.
- Upstream's changelog has fourteen release sections between the two, `1.24.3` to `1.28.3`. Its
  Stable-line patch tags (`v1.24.3`, `v1.25.6`, `v1.26.2` to `v1.26.4`, `v1.27.1` to `v1.27.4`) are
  not ancestors of `v1.28.3` and are not merged on their own. A comparison by commit subject finds
  their fixes on `v1.28.3`, with one exception: the 1.27.3 fix that gives a message its Send and
  Discard card when Stop puts it back in the box (`bf98ea86`) is on the 1.27 line only. Without it a
  Stop early in a Claude Code turn can leave later sends refused. Upstream restored it in `v1.28.4`,
  which is youngsecurity/collie#148.
- Integration is four commits: a two-parent merge, the removal of upstream's install ping, this
  record and the release commit. The release takes `1.28.3+ys.1` and carries an `**Urgent.**` line that names
  upstream's two urgent fixes in the range, because both apply to the fork.

## Adopted behavior

Three fixes the upstream changelog marks urgent, or that close a hole: Claude Code's Remote Control
row no longer makes Collie hold a message sent from the phone (1.28.3), Claude Code's session rating
no longer blocks every send (1.25.3), and `collie pair` refuses in a pane where an agent works, with
the origin of each pairing in the audit log (1.28.2).

Also the Herdr core (`herdr-core`) as a terminal host, the crew drawn by machine, launcher rows
owned by the crew's lead, crews on Windows behind a consent flag, a per-session WalkyTalky switch
and the WalkyTalky skill in each agent's skills folder, pinned messages, a status on each pane row,
the new default look and folder tabs, community themes, math rendering, and the Tasks and
background-job marks on the belt.

## Not adopted: the install ping

Upstream 1.27.0 sends one anonymous ping a day, on by default, and counts "Cannot read a dialog" and
"Send not landing" cards into it (upstream ADRs 0129 and 0134). The fork's ADR 0034 says Collie
collects nothing, and the operator chose to remove the ping rather than ship it off. The second
commit removes:

- `bridge/telemetry.ts`, its timers in `bridge/index.ts`, the routes `/api/telemetry` and
  `/api/telemetry/trouble`, the settings `telemetry` and `telemetry_url`, the two `telemetry.*`
  error codes and the receiver contract under `telemetry/`.
- The `telemetry` rows of `collie doctor`.
- The Settings card and page, the dashboard notice, the API client calls, the `telemetry.*` strings
  in all twelve languages and the `telemetry` icon key.
- The phone's trouble signal: `lib/report/once.ts`, `lib/report/screen.ts`, the signal half of
  `lib/report/signal.ts`, the "shown" callback of the unread-dialog card and
  `scripts/trouble-screens.ts`. The count leaves the machine only inside the ping, so without the
  ping it is dead code. Report a problem, which opens a draft the person sends, is kept whole.
- Upstream ADRs 0129 and 0134. ADR 0034 is `Accepted` again.

A `telemetry` key in `config.toml` or `COLLIE_TELEMETRY` in `.env`, left over from an upstream
install, is a named problem in `collie config check` and does not stop the bridge
(`bridge/config-source.test.ts`). `scripts/no-install-ping.test.ts` fails if a tracked file names
the ping's receiver or its User-Agent, or if the module, the route or the setting returns. The bool
setting option `words` had the ping's switch as its only user and went with it.

The other outbound calls upstream added in this range are kept. Each one happens only on a tap and
is described in `docs/security.md`: the community theme list (one `GET` to `colliepwa.dev`) and the
math engines download.
