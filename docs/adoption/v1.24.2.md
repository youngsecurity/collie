# Upstream v1.24.2 adoption

Issue: youngsecurity/collie#120.

## Pinned integration

This merge adopts the upstream tag onto the fork, directly on `dev-joe`.

- Fork base: `b754d06a` (`1.24.1+ys.1`).
- Upstream: `v1.24.2` (`2b292a5a`), a clean descendant of `v1.24.1`.
- The tag, not `upstream/main`: at merge time `main` was thirteen commits past the tag with
  unreleased `collie start` and `collie doctor` features. The release should be upstream's
  release; the next adoption takes those commits with theirs. Operator decision.
- Integration is a two-parent merge. The release commit after it takes `1.24.2+ys.1` and carries
  upstream's `**Urgent.**` line, because the fixes it names apply to the fork.

## Adopted behavior

A send that ended "typed, not submitted" on a slow disk now submits (the record is written after
the key goes out). Slash commands reach omp and pi under a live widget. pi under WSL submits with
Ctrl+Q. The phone's Update tap on a host with a named instance carries `COLLIE_INSTANCE`,
`COLLIE_MUX` and `COLLIE_CONFIG_DIR` into the runner, so it no longer updates the default instance
instead. Also OpenCode 2.1 and Hermes 0.22 readers, long question answers typed whole, linked
worktrees folded under their root on the dashboard, a microphone beside Attach while a draft is
held, and the browser leg's recorded model streams (M67, opt-in on this fork as before).
