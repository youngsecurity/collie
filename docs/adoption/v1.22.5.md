## Adopted behavior

The import includes server-owned Surface, Send and Ask protocols, durable-agent session
integration and SDK work, held sends, themes, harness readers and composer fixes. The
upstream changelog retains the detailed release-by-release history. The browser no longer
performs the old stranded-draft pre-clear sequence. It submits intent to the bridge and
renders the bridge's refusal, receipt or explicit follow-up offers instead.

Imported upstream ADRs remain alongside the fork amendments. Theme paint does not change
the literal inverse-video data used by readers and styled prompt binding. Device terminal
color overrides take precedence over theme paint. Literal inverse data also follows the
upstream adapters' mobile bright-fill handling. The full-width fork Chat layout and
pane-scoped preferences remain.
